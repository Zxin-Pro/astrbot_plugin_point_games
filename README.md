# 🎮 AstrBot 积分游戏

一个功能丰富的 AstrBot 积分小游戏插件：幸运转盘 / 闯关答题 / BOSS 战 / 大乐透 / 谁是卧底 / 签到排行。

- 🌐 **全群数据互通**：所有群的积分、排行榜、BOSS、奖池共享同一份数据
- 🔐 **群黑白名单**：默认全局关闭，由管理员按群开启或拉黑
- 🖥️ **WebUI 管理面板**：查看排行、流水、BOSS、奖池，管理群黑白名单与积分
- ⏰ **定时任务**：BOSS 每日 0 点重置，大乐透每日 20:00 自动开奖

## 安装

1. 将插件目录（或 zip）放入 AstrBot 的 `plugins/` 目录
2. 在 AstrBot 面板中启用插件「积分游戏」
3. 首次启用会自动创建数据表（使用 AstrBot 内置数据库）

依赖：`apscheduler`（`__requirements__` 已声明，AstrBot 会自动安装）

## 插件配置页

插件目录中的 `_conf_schema.json` 会自动生成 AstrBot 插件配置页。修改后重新加载插件即可生效，包含：

- 五个玩法及签到/排行开关
- 转盘默认消耗、六档概率权重、六档返还倍率
- 答题限时、答错扣分、连击奖励
- BOSS 血量、分红池、攻击消耗/冷却/伤害范围、重置时间
- 彩票默认注数、限购数量、保底奖池、中奖比例、开奖时间
- 卧底人数范围、报名/发言/投票时限
- 群默认白名单/黑名单模式
- 群号白名单/黑名单：在配置页直接填群号即可生效，插件加载时自动合并（可覆盖指令设置）
- 管理员QQ：`/积分 加积分` `/积分 减积分` `/积分 清除数据` `/积分 初始化` 仅名单内 QQ 可用（多个用逗号分隔）
- 每日签到：群内发送 `签到`、`jrzj` 或 `今日座驾`，会同时输出每日座驾和积分签到结果
- 每日座驾管理：群管理员可用 `添加车辆 车辆名称`、`删除车辆 车辆名称`，所有成员可用 `查看车池`
- 每日座驾配置：`car_pool` 车辆池、`reply_template` 回复模板，字段与原每日座驾插件一致
- 掷骰每日次数上限：`dice_daily_limit`，默认 5 次
- 群活跃奖励：每天按群统计发言，在 `activity_settle_hour:activity_settle_minute`（默认 22:00）结算前三名 +50/+30/+10
- 掷骰配置：`dice_daily_limit` 每人每日次数上限，默认 5 次
- 群活跃配置：`activity_settle_hour` 和 `activity_settle_minute`，默认每天 22:00 结算，奖励前三名 50/30/10 积分
- WebUI 玩家列表使用 QQ 昵称显示玩家，并支持查看收入、支出汇总和逐笔积分流水；每次使用插件会刷新昵称
- 签到回复顺序：积分签到结果 → 每日座驾

> 合并后请停用原「每日座驾」插件，避免同一条消息重复回复。

## 群黑白名单

防止玩法在所有群里都开着：

- **白名单模式（默认）**：所有群默认关闭，管理员在群里发 `/积分 本群玩法 开` 后才可玩
- **黑名单模式**：所有群默认开启，管理员发 `/积分 本群玩法 关` 拉黑该群
- 私聊不受黑白名单限制
- 全局模式切换：`/积分 玩法模式 白名单` 或 `/积分 玩法模式 黑名单`（管理员）

## WebUI 面板

### 方式一：插件页面（推荐）
插件自带 AstrBot 插件页面（`pages/panel/`）。打开方式：

1. 登录 AstrBot 面板
2. 进入「插件」→ 找到「积分游戏」→ 点击插件卡片进入详情页
3. 点击页面按钮「积分游戏面板」即可打开管理面板（插件 Web API 受面板登录保护）

> 若 iframe 内显示「加载失败」，说明当前 AstrBot 版本的页面沙箱限制了网络请求，请用方式二。

### 方式二：独立窗口面板
浏览器新窗口直接访问（自动兼容新版/旧版路由）：

- 新版地址：`/api/v1/plugins/extensions/point_games/dashboard`
- 兼容地址：`/api/plug/point_games/dashboard`

面板功能：总览统计、全服排行榜、BOSS 战况、大乐透奖池、完整积分流水、玩家昵称列表、群黑白名单管理、加/减积分。

> WebUI 管理操作面向所有已登录面板用户开放（插件 Web API 本身受面板登录保护）。

## 玩法规则

### 🎡 幸运转盘
随机 1-100：

| 点数 | 概率 | 返还 |
|---|---|---|
| 1-40 | 40% | 0 💀 |
| 41-70 | 30% | 50% 😅 |
| 71-85 | 15% | 80% 😌 |
| 86-95 | 10% | 120% 🙂 |
| 96-99 | 4% | 200% 🎉 |
| 100 | 1% | 500% 🔥 |

### 👹 BOSS 战
- 初始血量 10000，每日 0 点自动重置
- 每次攻击消耗 5 积分，造成 100-500 随机伤害，10 秒冷却
- BOSS 死亡时，500 积分奖池按伤害比例分给所有参与者，随后自动刷新

### 🎰 大乐透
- 每日 20:00 自动开奖，开奖号码 1-100 选 5 个
- 奖池 = 当日购买总额 + 保底 100 + 上期结转
- 命中 3 个 = 奖池 10%，4 个 = 30%，5 个 = 60%（同档多人平分）
- 无人中奖则奖池全额累积到下一期
- 开奖后向所有购买过的群 @全体 公布结果

### 🕵️ 谁是卧底
- 发起人 `/卧底开始 [人数]`，其他人 `/加入卧底` 报名，满员自动开局
- 系统从 35 组词库中随机选词，私聊发给每位玩家（私聊失败时退化为群内公布）
- 轮流发言（每人 120 秒），发言结束进入投票（60 秒）
- 票高者出局，平票无人出局；卧底出局平民胜，卧底活到最后 2 人卧底胜
- 管理员可随时 `/卧底结束`

### 💰 赞助积分系统
- 用户私聊机器人发送 `/赞助`，查看收款码和兑换率（默认1元=100积分）
- 支付时**务必备注QQ号**，支付后发送 `/赞助审核` 并引用（回复）订单截图
- 管理员收到提醒后，使用 `/赞助通过 [QQ] [积分]` 审核通过，积分自动到账
- 若截图有问题，使用 `/赞助拒绝 [QQ] [理由]` 拒绝申请
- 管理员可用 `/赞助列表` 查看待审核申请

#### 配置赞助功能
1. 准备收款码图片（支付宝/微信等）
2. 打开 AstrBot 面板 → 插件 → 积分游戏 → 配置
3. 找到「赞助收款码图片」，点击上传按钮，选择收款码图片
4. 设置其他配置项：
   - `sponsor_rate`：兑换率（1元=N积分，默认100）
   - `sponsor_admin_qq`：审核管理员QQ列表（多个用逗号分隔）
   - `sponsor_group_id`：提醒群ID（可选，填写后会在该群@管理员）
5. 保存配置并重新加载插件即可使用

> ⚠️ 收款码图片必须在配置页上传，用户发送 `/赞助` 时会显示该图片。

## 扩展新玩法

本插件按「玩法注册表」设计，新增玩法只需 3 步：

1. 在 `main.py` 的 `COMMAND_HELP` 中加一行 `(指令, 说明)`
2. 在插件类中新增 `@filter.command` 处理器 + 内部业务方法（复用 `self._tx`、`_balance`、`_add_points`、`_enforce_cooldown` 等公共工具）
3. 如需定时任务，在 `initialize()` 中 `add_job` 即可

`/积分 帮助` 介绍指令会自动展示新玩法，WebUI 无需改动。

## 常见问题

- **BOSS 血量没在 0 点重置？** 除了定时任务，攻击时也会按日期惰性重置，不会出现跨天不重置的情况
- **私聊发词失败？** 部分平台不支持主动私聊，会退化为群内公布，建议在支持私聊的平台（如 NapCat/OneBot）使用
- **WebUI 提示无权限？** 确认已登录 AstrBot 面板（插件 Web API 受面板登录保护）
